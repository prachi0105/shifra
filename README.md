# Shifra - Voice Assistant

Shifra is a responsive, web-based virtual voice assistant built using HTML, CSS, and JavaScript. It utilizes the Web Speech API to provide interactive voice recognition and synthesis, enabling users to execute various tasks and searches using custom voice commands.

## 🚀 Features

* **Speech Recognition:** Listens to user inputs in real-time using built-in browser speech-to-text.
* **Speech Synthesis:** Answers back with a clear, synthetic AI voice.
* **Smart Commands:** Formatted to respond to greetings, open popular websites (Google, YouTube, etc.), and perform web lookups.
* **Interactive UI:** Features a modern, dark-themed user interface complete with animated assets (`voice.gif`) and voice-activation controls.

## 🛠️ Tech Stack

* **HTML5:** Structured the voice activation interface and layout components.
* **CSS3:** Styled a clean, futuristic glassmorphism user interface.
* **JavaScript (ES6):** Implemented core backend logic utilizing the browser's native `SpeechRecognition` and `SpeechSynthesis` interfaces.
